# Building Placement Library

Portable editor tool for placing building/base pieces from prefabs.

Open from:

```text
Tools/Building/Base Placement Library
```

## What It Includes

- Browse prefabs from any folder.
- Place single prefabs at scene pivot, selected object, or origin.
- Pattern placement: line, grid, and circle.
- Grid snapping, ground alignment, spacing, offsets, rotation, scale, and parent container.
- Basic prefab diagnostics for renderers, colliders, and mesh filters.

## Design

This is an editor placement helper. It does not require a runtime building system.
