# Prototype Toolbox

Central launcher for portable editor tools in this project.

Open from:

```text
Tools/Prototype Toolbox
```

The toolbox opens:

- Game Data Workbench
- World Authoring Workbench
- Balance Board
- Quest NPC Flow Builder
- Character Job Preview Lab
- Combat Test Runner
- Building Placement Library
- Project Health Dashboard

It also exposes existing project utilities when their menu items exist.
