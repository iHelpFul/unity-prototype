# Character Job Preview Lab

Portable editor tool for inspecting jobs, appearance catalogs, and lightweight scene previews.

Open from:

```text
Tools/Characters/Job Preview Lab
```

## What It Includes

- Browse `PlayerJobDefinition` assets.
- See connected basic attack, animation profile, combat formula, default skills, and passives.
- Browse `CharacterAppearanceCatalogAsset` and see option counts plus palette preview.
- Place a preview prefab in the active scene for quick visual staging.

## Design

This tool does not modify runtime UI or character-selection flow. It is an authoring helper only.
