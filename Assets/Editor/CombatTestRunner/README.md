# Combat Test Runner

Portable editor tool for dry combat tuning previews.

Open from:

```text
Tools/Combat/Test Runner
```

## What It Includes

- Preview a `PlayerSkillDefinition` or `PlayerBasicAttackProfile` against an `EnemyDefinition`.
- Manual player test stats: base damage, hit rate, surge chance, surge power, element, and element power.
- Optional `CombatElementRuleProfile` support.
- Shows raw damage, element multiplier, defense mitigation, total per cast, target count, break power, and estimated casts to kill.

## Important

This is not a full runtime simulation. It is a fast dry preview for tuning direction before testing in Play Mode.
